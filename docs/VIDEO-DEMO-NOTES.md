# Demonstration video: preparation and disclosure checklist

The original screen recording is approximately **4 minutes 35 seconds** and contains identifiable project/drawing information and local file paths. **Do not upload the unedited recording to a public GitHub repository** without checking publication rights and redacting sensitive content.

## Disclosure checks

- Check permission to publish client/project drawings, quantities and project-specific information.
- Crop or blur project titles, file paths, personal/computer identifiers and any non-disclosable data **throughout the video**.
- Review the exported video at normal speed for identifiers appearing during pans, zooms or dialog transitions.
- Confirm that screenshots and sample data are cleared for public use.
- Never upload proprietary source code, client DWG files or raw field datasets unintentionally.
